# Changelog

## 1.0.5

- Added disposition icon overlays for friendly, neutral, hostile, and secret tokens.
- Added a client setting to show disposition icons at all times or only on token mouse-over.
- Positioned disposition icons in the lower-left token area to avoid covering the existing color indicator.
- Refined the hostile and secret disposition icons and versioned their asset URLs to avoid stale cached textures.
- Removed the hard maximum Foundry compatibility bound so current and future compatible versions can see the module listing.
- Added a license file and aligned release metadata for Foundry package installation.

## 1.0.3

- Updated manifest compatibility metadata to verify Foundry VTT 13.351.
- Changed the published author and attribution text to Marble Fox Games.
- Documented the module's Foundry compatibility and installation metadata more clearly.
- Corrected remaining text encoding artifacts and reduced duplicate token cleanup handlers.

## 1.0.2

- Added a single GM load-status message per module version instead of a whisper on every player load.
- Corrected user-facing text encoding issues in module UI strings.
- Updated manifest metadata to use stable GitHub release URLs for Foundry VTT installs and updates.
