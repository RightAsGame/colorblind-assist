# Colorblind Assist for Foundry VTT

**Author:** Marble Fox Games  
**License:** MIT-Attribution (Credit required)  
**Foundry Compatibility:** Minimum 11, verified on 13.351

A lightweight accessibility module that provides:

- Optional colorblind-mode filters (Protanopia, Deuteranopia, Tritanopia)
- Black-and-white textured rings for controlled and targeted tokens
- Disposition icons for friendly, neutral, hostile, and secret tokens, with a client setting to show them always or only on token mouse-over, matching the icon language used by Token Disposition Changer
- A high-contrast animated ping indicator visible to all colorblind modes.

This module is free to use and modify.  
Please include visible credit to **Marble Fox Games** when publishing derived works.

## Foundry v13.351 Notes

This release now targets Foundry Virtual Tabletop 13.351 in the manifest `compatibility.verified` field based on a static compatibility review of the package metadata and module code.

The module continues to use standard package metadata:

- `compatibility.minimum` defines the enforced minimum Foundry version.
- `compatibility.verified` identifies the specific declared Foundry build target.
- Root and release manifests are kept aligned for installs and updates.
